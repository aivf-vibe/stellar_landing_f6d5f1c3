# Higs Bar - Craft Brewery Landing Page

A modern, responsive landing page for Higs Bar craft brewery, featuring a warm and inviting design that captures the essence of artisanal beer crafting.

## Features

### 🍺 Design Highlights
- **Modern Brewery Aesthetic**: Warm color palette with gold (#d4a574) and dark tones
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth animations, hover effects, and engaging transitions
- **Professional Typography**: Playfair Display for headings, Open Sans for body text

### 📱 Sections Included
- **Hero Section**: Eye-catching introduction with animated beer glass
- **About Us**: Company story with brewing statistics
- **Our Beers**: Showcase of signature craft beers
- **Taproom**: Hours, features, and atmosphere details
- **FAQ**: Common questions with accordion functionality
- **Contact**: Location, hours, and social media links

### ⚡ Interactive Features
- Mobile-responsive navigation with hamburger menu
- Smooth scrolling between sections
- FAQ accordion with expand/collapse
- Animated counters for statistics
- Parallax effects and scroll animations
- Typing effect for hero subtitle
- Progress bar showing scroll position

### 🎨 Technical Implementation
- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern styling with Flexbox and Grid layouts
- **Vanilla JavaScript**: Interactive functionality without dependencies
- **Font Awesome**: Icons for enhanced visual appeal
- **Google Fonts**: Professional typography
